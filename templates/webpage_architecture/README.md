# Webpage Architecture Demo

Reusable vanilla HTML/CSS/JavaScript starter template for SAIRA.

## Structure

project-name/
├── index.html
├── css/style.css
├── js/main.js
├── assets/images/
└── README.md

## SAIRA workflow

When the user says **Create a webpage architecture**:
1. Ask for project name.
2. Create the project folder.
3. Copy this template.
4. Replace `PROJECT` / `Project Name` placeholders.
5. Open the new folder in VS Code.

No npm dependencies are required.
